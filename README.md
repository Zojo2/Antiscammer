# Antiscammer
A antiscammer tool with tools that can benefit both scambaiters, average people, and people like the elderly that are targeted for scams. It has a variety of tools that can be used for the express purpose of stopping a scammers remote tools in their tracks.
Ctrl alt p: Panic button to cut off all scammer connection
Ctrl alt s: disable scammer black screen
Ctrl alt I: disable scammers input blocker
ctrl alt K: kill all connections to computer to stop scammer as a panic last resort
ctrl alt R: restore network
ctrl alt L: capture all evidence from the scammer including IP of the scammer and ports the scammer is on.
